# FedStay — Federated & Privacy-Preserving Patient Length of Stay Prediction

## Overview
FedStay predicts hospital length of stay using machine learning while simulating a privacy-preserving federated setup across 3 hospital sites.

## Project Structure
- `data/`: Raw dataset and federated site splits.
- `main.py`: End-to-end execution pipeline.
- `results/charts/`: Visualizations including ROC comparisons and feature importance plots.
- `report.md`: Summary of findings and research utility.

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
